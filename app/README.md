# WS4 — Web app

Next.js (App Router) + TypeScript + Tailwind + shadcn/ui + Solana wallet adapter (Phantom) + Recharts.

## Screens (P0)

| Screen | Job |
|--------|-----|
| Buy | Call series picker, BS vs crowd, quantity, buy tx |
| Protect | Exact-share puts for advisors (lead demo: 44 shares) |
| Vault | Solvency panel, LP deposit/withdraw, netting meter, trade tape |

Scaffold only — App Router pages and wallet wiring start at M4. Depends on WS1 IDL and WS2 API schemas.

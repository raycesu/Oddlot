# Frozen API schemas (WS2)

JSON Schema drafts for the pricer HTTP surface. M0 freezes these shapes.

| File | Endpoint |
|------|----------|
| `quotes.schema.json` | `GET /quotes` |
| `book.schema.json` | `GET /book` |
| `distribution.schema.json` | `GET /distribution` |
| `trades.schema.json` | `GET /trades` |
| `simulation.schema.json` | `GET /simulation` |

Money values are decimal USD strings. Times are ISO 8601 UTC.
